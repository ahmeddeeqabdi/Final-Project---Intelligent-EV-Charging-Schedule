# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Report a vulnerability privately through GitHub's **Security** tab by selecting **Report a vulnerability**. Include the affected component, reproduction steps, potential impact, and any suggested mitigation.

You can expect an initial response within seven days. Confirmed issues will be prioritized according to severity and disclosed after a fix is available.

## Supported versions

Security fixes are applied to the latest version on the default branch.
